# ReD-Pot — components (lightweight by design)

No Elasticsearch / Logstash / Kibana. Measured footprint on 1.0.0: **~140 MB RAM** for the manager + 2 decoys
(about 50 MB per extra decoy), one ~280 MB Docker image.

| Layer | Component | Notes |
|---|---|---|
| Language | Python 3.13 (in the image); installer needs only the host's python3 | sensors, console, CLI |
| Storage | SQLite (WAL), one file | no DB server; PostgreSQL optional later for large MSSP setups |
| Console | Flask + cheroot (TLS) | single process, two HTTPS ports (UI, sensor API), no reverse proxy required |
| Dashboard | vanilla HTML/JS + vis-network 9.1.9 (vendored) | works offline / air-gapped, no build step |
| SSH | paramiko | simulated shell, nothing executed |
| SMB | impacket SimpleSMBServer + SMB2 hooks + own NTLM/negotiate persona (`rpot/sensor/ntlmauth.py`) | read-only bait shares, bait-only named logons |
| HTTP, FTP, RDP, MSRPC, NetBIOS | own code (stdlib; RDP CredSSP uses impacket's NTLM structures) | persona banners |
| LDAP / LDAPS / GC, Kerberos KDC, DNS | own code (stdlib, bounded BER codec) | Domain Controller + DNS roles; never issues tickets, never recurses |
| TLS / keys | cryptography | per-persona certs + SSH keys |
| GeoIP | DB-IP Lite mmdb (CC BY 4.0) + maxminddb | offline; country+ASN ~18 MB, city ~130 MB optional |
| World map | world-atlas 110m TopoJSON + topojson-client (vendored), own canvas renderer | no map tiles, works offline |
| Alerts / export | `alerts.json` (+ optional `events.json`) JSON Lines with rotation; JSON export of incidents + alert records | no outbound alerting, nothing leaves the manager |
| Deploy | Docker Compose, 1 container per role; production decoys in the host network on their interface's own IP, lab decoys on an isolated bridge | `rpotctl.py compose` |
| Host firewall | iptables / ip6tables script generated by the installer | decoy-interface policy, admin allow-lists, decoy egress guard, TTL 128 for Windows decoys |
| Sensor link | HTTPS keep-alive, certificate pinned by SHA-256, gzip batches | ~0.6 kbit/s per idle sensor |
